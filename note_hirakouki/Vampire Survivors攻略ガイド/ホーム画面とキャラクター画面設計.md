# ホーム画面とキャラクター画面設計

最終確認日：2026-11-10  
このノートは、現在のWebサイトに実装されているホーム画面とキャラクター一覧画面の設計・仕様をまとめる。古いコード全文の複製ではなく、実装の意図・画面差分・未実装部分を記録する。

実際のコードは [vampire-survivors-wiki/website](https://github.com/vampire-survivors-wiki/website) を正本とする。リポジトリ上のファイルを直接編集し、このノートにコードを重複して保管しない。

全体の実装状況は [[Vampire Survivors攻略ガイド/現行実装状況]]、サイト構成の目標は [[Vampire Survivors攻略ガイド/サイト構成・コンテンツ分類]] を参照。

## 1. 実装対象のページ

| ページ | URL | 状態 |
|---|---|---|
| ホーム | / | PC版・スマートフォン版を実装 |
| キャラクター一覧 | /characters/ | PC版・スマートフォン版を実装 |
| キャラクター詳細 | 未設定 | 未実装 |

ページの切り替えはAstroのページ単位で行う。ホームとキャラクター一覧では共通のLayoutを利用し、表示内容はPC用・スマートフォン用のコンポーネントに分けている。

## 2. ホーム画面

### 2.1 ページ構成

ホームは、次の順番でコンテンツの入口を案内する。

1. 攻略
2. 金策
3. アップデート
4. note
5. YouTube

#### 攻略

4つの入口を表示する。

- ステージ攻略
- ボス攻略
- キャラクター
- アンロック

#### 金策

2つの入口を表示する。

- 仕組み・解説
- 金策構築

#### アップデート

パッチ履歴・DLC追加要素を案内するカードを表示する。

#### note・YouTube

noteの攻略・解説記事集とYouTube攻略動画への外部リンクを表示する。専用のnoteページ・YouTube一覧ページはまだ実装していない。

### 2.2 PC版とスマートフォン版の構成

実装ファイル：

- PC版：src/components/home/HomeDesktop.astro
- スマートフォン版：src/components/home/HomeMobile.astro
- ページ切り替え：src/pages/index.astro

画面幅に応じてPC版・スマートフォン版の表示を切り替える。単純にPC版のカードを縮小するのではなく、コンテンツ量と操作方法を調整する。

| 項目 | PC版 | スマートフォン版 |
|---|---|---|
| 攻略カード | 4枚のカード。見出し・説明文・開くリンクを表示 | 4枚のカード。PC版と同じ長さの説明文を表示 |
| 攻略カードのリンク範囲 | 「開く →」のみ | カード全体 |
| 金策 | 仕組み・解説、金策構築の2カード。英語補助ラベルも表示 | 2項目をコンパクトに表示。英語補助ラベルは省略 |
| アップデート | 説明を含むカード | 重複する補助文を省略し、短い説明を表示 |
| note・YouTube | それぞれの外部リンクをカードで表示 | 外部リンクをコンパクトに表示 |

### 2.3 攻略カードのリンク仕様

PC版では、カード全体ではなく「開く →」だけをリンクにする。見出しと説明文はリンク範囲に含めない。

4つのリンクには、スクリーンリーダーで行き先を区別できるように、見出しを含む個別のaria-labelを設定する。

スマートフォン版はカード全体をリンクにする。PC版のリンク範囲変更はスマートフォン版には適用していない。

現状、キャラクターの入口は /characters/ へ移動する。ステージ・ボス・アンロックなどの専用ページは未実装で、仮リンクが残っている。金策・アップデートも専用ページへのリンク先は未完成。

### 2.4 モバイル表示で省略している情報

スマートフォン版では、カードの説明を読める長さで維持しながら、重複する補助ラベルを省略する。

- 金策「仕組み・解説」の英語ラベル THEORY & MECHANICS は表示しない。
- 金策構築の英語ラベル OPTIMIZED BUILDS は表示しない。
- アップデート項目の「パッチ履歴・DLC追加要素の検証アーカイブ」という補助文は表示しない。
- 攻略4カードの説明文は短縮しない。

### 2.5 現在の未実装項目

- 攻略4カードのリンク先となる専用一覧ページ
- 金策トップ・金策解説・金策構築一覧
- アップデート情報ページ
- note専用ページ・タグ別記事一覧
- YouTube動画一覧ページ

## 3. キャラクター一覧画面

### 3.1 実装ファイル

- ページ：src/pages/characters/index.astro
- キャラクター基本データ：src/data/characters.ts
- PC・スマートフォン共通の表示対象：src/data/character-display.ts
- PC版：src/components/characters/CharactersDesktop.astro
- スマートフォン版：src/components/characters/CharactersMobile.astro

### 3.2 表示対象データ

characters.tsには28件のキャラクターデータを定義している。現在の画面に表示する対象はcharacter-display.tsで選定し、各グループから1件ずつ、合計3件としている。

- 通常キャラクター：アントニオ
- 隠しキャラクター：ビッグ・トラウザー
- DLC：サミー

PC版とスマートフォン版は、同じcharacterDisplayGroupsを利用する。各画面に個別の選定条件を持たせず、表示対象がずれない構成としている。

### 3.3 PC版

- 通常キャラクター・隠しキャラクター・Foscariの潮流の3グループに分けて表示する。
- カードには画像、日本語名、英語名、初期武器を表示する。
- 画像がない場合は、キャラクターごとのSVGアイコンを代替表示する。
- 表示分類の切り替えボタンを配置する。
- 「全キャラクター」「通常キャラクター」「隠しキャラクター」「Foscariの潮流」の件数は、表示データから動的に算出する。
- 選択した分類以外のセクションは非表示にする。

### 3.4 スマートフォン版

- PC版と同じ3グループ・同じ3キャラクターを表示する。
- 2列のグリッドで、画像を大きく見せる。
- 画像の下には日本語名を表示する。
- PC版にあるフィルター操作、英語名、初期武器は表示しない。
- グループを順番にスクロールして確認する構成とする。

### 3.5 現在の未実装項目

- 28件すべてを画面に表示すること
- キャラクター詳細ページ
- 一覧カードから詳細ページへのリンク
- 入手方法・性能の個別解説
- 一覧上で情報をどこまで表示するかの最終判断

キャラクター情報を一覧と個別詳細ページに分けるか、一覧画面を中心に情報を追加していくかは、記事作成の負担と更新のしやすさを考慮して今後決定する。

## 4. 共通レイアウト

共通コンポーネント：

- Layout：ページ全体のHTML構造、meta情報、共通部品の配置
- Header：PC版のグローバルナビゲーションとスマートフォン版のメニューボタン
- MobileDrawer：スマートフォン用のドロワーメニュー
- Footer：PC版・スマートフォン版のフッター

### ヘッダー・ナビゲーション

PC版はヘッダーに横並びでリンクを配置する。スマートフォン版はハンバーガーボタンからドロワーを開く。

スマートフォンのドロワーには、ホーム、キャラクター一覧、準備中の攻略・金策・アップデート項目、note、YouTubeを表示する。準備中の項目は、専用ページが実装済みであることを意味しない。

### デザインの現状

- 明るいアイシーブルー系のグラデーション背景
- 白を基調とした半透明のフロストガラス風パネル
- Slate系の文字色・境界線
- Plus Jakarta Sans、Noto Sans JP、JetBrains Monoを使用
- PCとスマートフォンでレイアウトを分け、コンテンツ量と操作に応じて表示を調整

この見た目は現在の初期実装の基準であり、今後のページ追加時にも読みやすさと一貫性を確認しながら調整する。

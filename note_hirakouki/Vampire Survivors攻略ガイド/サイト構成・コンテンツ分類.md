# サイト構成・コンテンツ分類

このノートでは、Vampire Survivors攻略サイトのページ構成、グローバルメニュー、記事を作る単位を整理する。

このノートは、最終的に目指すページ構成・コンテンツ分類を整理する。現在の実装済みページと未実装ページは [[現行実装状況]] を正本として確認し、目標構成と現状を混同しない。

## 1. グローバルメニュー案

目標とするグローバルメニュー：

1. ホーム
2. 攻略
3. 金策
4. アップデート
5. note（表示名は検討中）
6. YouTube動画（表示名は検討中）

noteとYouTubeは、攻略記事の中に必ず含めるのではなく、それぞれ独立したコンテンツページを用意する。

### グローバルメニューの移動先

**グローバルメニューを選択したときは、基本的に各コンテンツのトップページ・入口ページ・一覧ページへ移動する。個別の攻略記事へ直接移動させるのではなく、まず目的のコンテンツを選べるページを開く。**

| メニュー | 移動先 |
|---|---|
| ホーム | ホーム |
| 攻略 | ステージ攻略・ボス攻略・キャラクター情報・アンロック攻略を選ぶ攻略トップ |
| 金策 | 仕組み・基本解説と金策構築一覧への入口となる金策トップ |
| アップデート | 最新バージョンと過去バージョンを確認できるアップデートページ |
| note | noteリンク集・タグ別記事への入口ページ |
| YouTube | 投稿動画一覧ページ |

現在の実装では、PCヘッダーから攻略・金策・アップデートのホーム内セクションへ移動し、キャラクターは /characters/ へ移動する。note・YouTubeは外部サイトへ直接移動する。スマートフォンのドロワーには、ホーム・キャラクター一覧・準備中の攻略/金策/アップデート・note・YouTubeを表示している。独立した攻略トップ・金策トップ・アップデート・note・YouTubeページは未実装。実装状態は [[現行実装状況]] を参照する。

### パンくずリスト

パンくずリストは、基本的に **「ホーム ＞ コンテンツ ＞ コンテンツ内のカテゴリ・一覧 ＞ 個別の名前」** の階層で表示する。

例：

- ステージ攻略：ホーム ＞ 攻略 ＞ ステージ攻略 ＞ ステージ名
- ボス攻略：ホーム ＞ 攻略 ＞ ボス攻略 ＞ ボス名
- キャラクター詳細：ホーム ＞ 攻略 ＞ キャラクター情報 ＞ キャラクター名
- アンロック一覧：ホーム ＞ 攻略 ＞ アンロック攻略 ＞ 本編／DLC名
- 金策構築：ホーム ＞ 金策 ＞ 金策構築 ＞ キャラクター名・構築名
- 金策の仕組み・基本解説：ホーム ＞ 金策 ＞ 仕組み・基本解説

ページ階層が少ないコンテンツでは、存在しないカテゴリ階層を無理に追加しない。

### サイドバー

**PC版の記事ではサイドバーに目次を表示する。スマートフォン版では目次を設置しない。** サイト全体のコンテンツ移動は上部のグローバルメニューで行うため、サイドバーにサイト内ナビゲーションや関連記事を重ねて置かない。

## 2. ホーム

ホームは、**サイト内にあるすべてのコンテンツへの案内役・全体案内図**として設ける。

読者がサイトに何の情報があるのかを把握し、目的に合ったページへ移動できるようにする。主要なコンテンツの入口を整理して掲載し、各カテゴリ・一覧ページを経由して個別の記事にもたどり着ける構成にする。

### ホームの掲載順

ホームのコンテンツは、次の順番で掲載する。

1. **攻略**
2. **金策**
3. **アップデート**
4. **note**
5. **YouTube**

### 各セクションの掲載内容

- **攻略**：ステージ攻略、ボス攻略、キャラクター情報、アンロック攻略の4つの入口を掲載する。本編・DLCの個別項目をホームにすべて並べるのではなく、攻略トップや各カテゴリ一覧へ案内する。
- **金策**：「仕組み・基本解説」と「金策構築一覧」の2つの入口を掲載する。金策構築の個別記事をすべてホームに並べるのではなく、金策トップへ案内する。
- **アップデート**：アップデートページへの入口を掲載する。最新バージョンや過去バージョンの情報をホームに重複掲載しない。
- **note**：noteページへの入口を掲載する。noteリンク集やタグ別記事はnoteページ側で確認できるようにする。
- **YouTube**：YouTube動画一覧ページへの入口を掲載する。動画の一覧はYouTubeページ側で確認できるようにする。

ホーム上に個別記事や動画を大量に並べるのではなく、コンテンツのまとまりごとに入口を設け、各カテゴリ・一覧ページから個別の情報へ進めるようにする。

検索エンジン・note・YouTubeなどから個別記事へ直接訪問するケースも引き続き重視する。ホームは全体を見渡すための案内ページであり、すべての読者が必ず経由する前提にはしない。

現在のホームにはこの5セクションを実装済み。PC版とスマートフォン版は別コンポーネントで、説明文の長さやカードのリンク範囲を画面に合わせて調整している。PC版は「開く →」だけをリンクにし、スマートフォン版はカード全体をリンクにする。リンク先ページが未実装のカードには仮リンクが残っている。詳細は [[ホーム画面とキャラクター画面設計]] を参照する。

今後追加するカテゴリ一覧や記事ページの具体的なレイアウト、画像の使い方、表示形式は、参考サイトの調査・比較を行ってから検討する。

## 3. 攻略

攻略トップでは、本編・DLCを最初に選ばせるのではなく、**攻略したいコンテンツの種類から選べるようにする**。

攻略トップに表示する主な入口は次の4種類とする。

- ステージ攻略
- ボス攻略
- キャラクター情報
- アンロック攻略

本編とDLCは独立した選択専用ページを挟まず、それぞれの種類の一覧ページ内で分類する。読者は「ステージ攻略」「ボス攻略」など目的の種類を選んだ後、その一覧の中で本編または目的のDLCの情報を探せるようにする。

### 3.1 ステージ攻略

- ステージごとに攻略記事を作成する。
- ステージ攻略の一覧ページ内で、本編のステージとDLCごとのステージを分けて掲載する。
- **並び順は本編を最初にし、その後にDLCを掲載する。DLCは新しいものから順番にする。**
- 一覧には、基本的に**画像とステージ名のみ**を表示する。短い説明文や詳細な攻略情報は載せず、攻略記事側で確認してもらう。
- 本編と各DLCの区切りは、基本的に見出しや区切り線で表現する。
- ステージ専用一覧ページは未実装。ホームの入口はカード形式で実装済みだが、専用一覧ページのレイアウトは未決定とする。
- 30分生存など、そのステージのクリアを目的とした攻略を扱う。

### 3.2 ボス攻略

- ボスごとに独立した攻略記事を作成する。
- ボス攻略の一覧ページ内で、本編のボスとDLCごとのボスを分けて掲載する。
- **並び順は、基本的にボスが出現するステージの順番にする。**
- 一覧には、基本的に画像とボス名を表示する。
- ボスの倒し方や、撃破に必要な準備・手順を扱う。

### 3.3 キャラクター情報

キャラクター情報の現在の実装は、/characters/ の一覧ページのみ。キャラクターごとの詳細ページはまだ実装していない。

#### 現在実装している一覧ページ

- キャラクターデータは28件を管理しているが、画面に表示する対象は現在3件（通常・隠し・DLCから1件ずつ）。
- PC版・スマートフォン版は同じ表示対象データを共有する。
- PC版は通常・隠し・DLCの3グループをカード形式で表示し、画像・日本語名・英語名・初期武器を掲載する。
- PC版には「全キャラクター」「通常キャラクター」「隠しキャラクター」「Foscariの潮流」の分類切り替えを設け、表示件数はデータに連動させる。
- スマートフォン版は2列の画像中心カードと日本語名のみで構成し、フィルターは設けず、3グループを順番に表示する。
- 現在のカードはキャラクター詳細ページへのリンクではない。
- 現行の一覧にはサイト全体の検索・ソート機能は設けていない。

#### 今後のキャラクター情報の構成

詳細情報の掲載方法は、一覧ページと個別詳細ページのどちらかに固定しない。記事作成の負担や段階的な公開のしやすさも考慮し、一覧ページ内で説明を充実させる方法と個別詳細ページを設ける方法を比較して決定する。

性能の説明では、ゲーム内の説明をそのまま載せるだけではなく、固有能力やステータスの具体的な挙動を詳しく扱う。必要に応じて、既存のnote記事を参考にする。

- [レガシー・オブ・ザ・ブラッドムーン キャラクター解説](https://note.com/neo_magical/n/n9682c7eeb0c9)
- [アンティの間 キャラクター解説](https://note.com/neo_magical/n/ndc25347a5015)

### 3.4 アンロック攻略

アンロック攻略は、**入口となる一覧ページと、本編・DLCごとのアンロック一覧ページ**で構成する。アンロック1件ごとの個別詳細ページは作成しない。

#### アンロック攻略の入口ページ

- 本編と各DLCへのリンクを一覧で掲載する。
- 本編とDLCを分け、DLCはDLCごとに選べるようにする。
- このページは目的のアンロック一覧へ移動するための案内役とし、個々のアンロック情報は掲載しない。

#### 本編・DLCごとのアンロック一覧ページ

- 本編用の一覧ページを1つ、DLCごとにそれぞれ1つ作成する。
- **本編はゲーム内の並び順で掲載する。各DLC内もゲーム内の並び順を基準にする。**
- 各アンロックには、画像・アンロック名・達成条件・達成報酬を掲載する。
- 条件の説明に補足が必要な場合は、該当するアンロックの情報内に補足を含める。アンロック単位の別ページは作らない。
- 本編に最初から存在するすべてのアンロックを網羅する方針ではなく、基本的にDLCやアップデートで追加された新しいアンロックを対象にする。

## 4. 金策

攻略とは独立したメニューにする。**金策トップページを入口として用意し、その中から「仕組み・基本解説」と「金策構築一覧」へ移動できる構成にする。**

### 金策トップページ

- 金策全体の入口となるページを作成する。
- 「金策の仕組み・基本解説」と「金策構築一覧」の2つを案内する。
- グローバルメニューの「金策」を選択したときは、このページへ移動する。

### 4.1 金策の仕組み・基本解説

金策全体の知識をまとめ、個別の金策構築を理解するための基礎情報を提供する。基本構成は以下の8項目とする。

| 順番 | 見出し | 内容 |
|---|---|---|
| 1 | 目次（PC版のみ） | PC版サイドバーからの記事内案内 |
| 2 | 金策の種類 | ゴールドフィーバー、金貨袋、悪食の瞳など |
| 3 | ゴールドフィーバーの仕組み | 発動条件、持続時間、延長、減衰など |
| 4 | 金策向けキャラクター | ビッグ・トラウザー、サミーなど |
| 5 | 金策向け武器 | 金策に使える武器と効果 |
| 6 | 金策向けアルカナ | それぞれの効果と採用する理由 |
| 7 | 金策に関係する設定 | ステージ設定、ゲーム速度、エフェクトなど |
| 8 | 効率の検証・比較 | 実際のプレイ結果を使った比較 |

キャラクター・武器・アルカナ・設定は、性能を並べるだけではなく、金策にどう役立つのか、なぜ採用するのかまで説明する。具体的な構築や実践手順は金策構築の記事で扱う。基本解説と構築記事はそれぞれ単体で目的を果たせる内容にする。関連記事やサイト内ナビゲーションをサイドバーに置かない。PC版の記事ではサイドバーに目次を表示し、スマートフォン版では目次を設置しない。

効率の検証・比較では、実際のプレイ結果を使い、検証した条件と結果が分かるようにする。確認できた内容と推測は区別する。

### 4.2 金策構築

キャラクターや金策方法に応じて、実際に使用する構築と稼ぎ方を紹介する。基本的にはnoteの記事構成を参考に、次の内容をひとつの記事内で扱う。

1. 目次（PC版のみ。サイドバーに表示）
2. キャラクターの性能・評価
3. 使用ステージ・設定
4. **金策構築・実践方法**

「金策構築・実践方法」の中に、武器・パッシブ・アルカナなどの構成、取得順や立ち回り、実際の稼ぎ方、検証結果をまとめる。黄金の卵の段階によって構築が異なる場合も、原則として同じ記事内で紹介する。**金策構築の種類は、現状の2体のキャラクターによる構築を基本とし、新しい構築が実際に増えた場合に同じ一覧へ追加する。現時点で細かな分類や拡張用の複雑な仕組みは設けない。**

検証結果は独立した大見出しにせず、実際の構築・稼ぎ方と関連付けて掲載する。稼げたゴールド量や所要時間などを示し、複数条件を比較する場合は表や画像などで分かりやすく整理する。

### 4.3 金策構築一覧

- 実際の金策構築を一覧で掲載し、各構築の個別記事へ移動できるようにする。
- 現在はビッグ・トラウザーとサミーの構築を掲載する。
- 新しい金策構築が増えた場合は、同じ一覧に追加する。
- 現時点では、キャラクターや構築条件による複雑な分類・検索機能は設けない。

## 5. アップデート

**アップデート情報は専用の1ページにまとめ、バージョン一覧ページやバージョンごとの独立ページは作成しない。**

- ページの最上部には、**最新バージョンのアップデート情報を通常表示する**。
- 最新バージョンの下に「過去のアップデート情報」を設け、**過去の各バージョンを開閉式（アコーディオン形式）で格納し、初期状態では閉じておく**。
- 過去のバージョンを確認したい読者は、該当するバージョンの見出しを開いて内容を読む。
- 新しいバージョンが追加されたら、その内容を最新バージョンとして通常表示し、それまで最新だったバージョンは過去のアップデート情報の開閉項目へ移す。
- **アップデート情報の文章・内容は、noteに掲載したものを原則そのまま使用する。サイト向けに要約・再構成しない。**
- 無料アップデートとDLCの内容は、同じバージョンに属する場合は分けずに同じバージョンの情報内で扱う。
- 既存の攻略方法に影響する変更があれば、そのバージョンの情報内で変更点と影響を説明する。
- 記事末尾に関連記事・おすすめ記事をまとめる枠は設けない。PC版の記事ではサイドバーに目次を表示し、スマートフォン版では目次を設置しない。

速報性の高い情報はnoteで先に発信し、Webサイトでは最新情報をすぐ確認できる状態にしつつ、過去の情報は折りたたんで参照できるようにする。

## 6. note

noteページは、Webサイトからnoteへ移動するためのシンプルな入口として設ける。noteの記事内容をWebサイト側で詳しく紹介したり、独自の大規模な記事アーカイブを作ったりすることは目的にしない。

ページの構成は次のとおり。

1. **既存のnoteリンク集を最上部に掲載する。**  
   [note記事のリンク集](https://note.com/neo_magical/n/n6770c38d1b1c) を、noteに掲載している記事全体を探すための入口として案内する。
2. **その下に、既存のnoteリンク集と基本的に同じタグ分類でnote記事を掲載する。**  
   Webサイト側で独自のタグ体系を新しく作るのではなく、リンク集ですでに使っている分類を基準に記事を整理する。

noteページはnoteへの入口として必要な案内に絞り、記事ごとの長い説明や複雑な検索・絞り込み機能などは、必要性が出るまで設けない。

## 7. YouTube動画

YouTubeページは、WebサイトからYouTubeへ移動するためのシンプルな入口として設ける。動画をWebサイト内で詳しく解説したり、独自の動画アーカイブとして作り込んだりすることは目的にしない。

- **最新動画をページの最上部に大きく表示する。**
- **最新動画の下には、それより小さい表示枠で過去の動画を並べる。** 2番目以降も新しい順に掲載する。
- 動画を見たい読者は、各動画の表示からYouTubeへ移動して視聴する。
- YouTubeページ内で動画を埋め込んで再生することは基本としない。動画の表示枠はYouTubeへ移動するためのサムネイル・リンクとして扱う。
- 攻略に直接関係する動画は、該当する攻略ページに埋め込む。YouTubeページと攻略ページで役割を分ける。

最新動画を目立たせ、それ以外の動画はコンパクトに一覧できるシンプルな構成にする。

## 8. 一覧ページの共通方針

サイト内の各コンテンツ一覧では、**原則としてサイト全体検索・ソート機能を設けない**。PC版キャラクター一覧にあるカテゴリ切り替えは、現在の画面で実装している表示範囲の切り替えとして例外扱いにする。スマートフォン版キャラクター一覧はカテゴリ別セクションをそのまま表示し、フィルターは設けない。

- カテゴリやコンテンツのまとまりをあらかじめ分け、分かりやすい固定順で掲載する。
- 読者はGoogleなどの検索エンジンで目的の情報を探してから訪問することが多い想定のため、一覧ページでもう一度検索や絞り込みをさせない。
- 利用頻度が高くないと考えられる機能を追加して、読者に余分な操作を求めない。
- 一覧の情報量が増えても、まずは分類と並び順を工夫して目的の記事を見つけやすくする。
- ステージ・ボス・キャラクター・アンロックなど、個別コンテンツを一覧表示する場合は、**基本的に画像と名称のみ**を表示する。詳しい説明文や性能情報は一覧に詰め込まず、移動先の記事・ページ内の解説で確認してもらう。ただし、アンロックは個別詳細ページを作らないため、一覧内でどこまで情報を掲載するかは別途決める。
- 本編と各DLCの区切りは、基本的に見出しや区切り線で表現する。
- ホームの入口カードとキャラクター一覧のカードグリッドは実装済み。
- ステージ・ボス・アンロックなど、今後追加する専用一覧ページのレイアウトは未決定とする。カード形式を前提にせず、リスト型なども比較する。
- 特にスマートフォン表示は、実際の情報量を当てはめ、読みやすさと操作性を確認して調整する。

この方針はステージ・ボス・キャラクター・アンロックなど、サイト内の各一覧ページに共通して適用する。

## 9. 記事の管理単位（現時点の決定）

| コンテンツ | 記事を作る単位 |
|---|---|
| ステージ攻略 | ステージごと |
| ボス攻略 | ボスごと。ボス一覧は本編・DLC別に分け、基本的に出現ステージ順で掲載 |
| キャラクター攻略 | 本編・DLC別・ゲーム内順の一覧ページと、キャラクターごとの詳細ページ |
| アンロック攻略 | 入口ページから本編・各DLCのアンロック一覧ページへ移動する。各ページ内で画像・名称・達成条件・達成報酬を掲載。アンロック1件ごとの個別ページは作らない |
| DLC | DLCごとに情報を分類 |
| 金策トップ | 仕組み・基本解説と金策構築一覧への入口 |
| 金策の仕組み・基本解説 | 仕組み・テーマごと |
| 金策構築一覧 | 現在の金策構築を一覧表示し、各構築記事へ案内 |
| 金策構築記事 | キャラクター・金策方法ごと（卵数段階などの構築差は同一記事内にまとめる） |
| アップデート | 1ページにまとめる。最新バージョンは通常表示し、過去バージョンはページ下部の開閉式の中に格納する。無料アップデートとDLCは同じバージョン内で扱い、noteの内容を原則そのまま掲載 |
| note | 既存のnoteリンク集を先頭に掲載し、その下にリンク集と基本的に同じタグ分類でnote記事へのリンクを整理 |
| YouTube | 最新動画を最上部に大きく表示し、その下に過去動画を小さく新しい順に並べ、YouTubeへ移動する入口 |

## 10. 訪問・閲覧の考え方

読者は「このWikiを見て何かを探す」というより、「知りたい情報があるから、このサイトを見る」という目的を持って訪れることを想定する。

そのため、検索エンジンやnote、YouTubeなどから個別記事へ直接アクセスするケースを重視する。

個別記事はトップページを見ていなくても、記事単体で目的や内容が分かり、その記事内で必要な情報に到達できるようにする。**記事末尾に関連記事やおすすめコンテンツを並べることはしない。** サイト全体の移動は上部のグローバルメニューで行い、PC版の記事ではページ横のサイドバーに目次を表示し、スマートフォン版では目次を設置しない。

トップページは重要な入口の1つではあるが、必ず経由する前提にはしない。

## 11. 今後検討すること

- ホームの各セクションの具体的なレイアウト・画像・表示形式
- 各攻略カテゴリ一覧での画像・名称の具体的な表示レイアウト

# サイト構成・コンテンツ分類

このノートでは、Vampire Survivors攻略サイトのページ構成、グローバルメニュー、記事を作る単位を整理する。

現時点で決まっている内容と、今後検討する内容を区別する。未決定の項目を無理に確定させない。

## 1. グローバルメニュー案

現時点の候補：

1. ホーム
2. 攻略
3. 金策
4. アップデート
5. note（表示名は検討中）
6. YouTube動画（表示名は検討中）

noteとYouTubeは、攻略記事の中に必ず含めるのではなく、それぞれ独立したコンテンツページを用意する。

## 2. ホーム

各コンテンツへの入口となるページ。

このサイトは、目的が定まった読者が特定の記事を探しに来ることを想定しており、トップページが主な流入元になるとは限らない。検索エンジン、note、YouTubeなどから個別記事へ直接訪問するケースも重視する。

そのため、トップページだけでなく、個別記事や各一覧ページからも必要な情報にアクセスできることを大切にする。トップページを豪華にすることや、回遊を促すこと自体を目的にしない。

トップページに何を掲載するか、どの順序で配置するかは未決定。

## 3. 攻略

攻略情報は、本編（DLCなし）とDLCごとに分けて整理する。

### 3.1 本編（DLCなし）

#### ステージ攻略

- ステージごとに攻略記事を作成する。
- 30分生存など、そのステージのクリアを目的とした攻略を扱う。

#### ボス攻略

- ボスごとに独立した攻略記事を作成する。
- ボスの倒し方や、撃破に必要な準備・手順を扱う。

#### キャラクター攻略

- 本編・DLCごとにキャラクターをまとめたページを作成する。
- キャラクター一覧は常時表示の大きな一覧にはせず、折りたたみ式で設ける。初期状態では閉じておき、必要な読者だけが開いてキャラクターを選べるようにする。
- 一覧内のキャラクター名から、同じページ内の該当する詳細解説へ移動できるようにする。
- 通常の目次にはページ全体の主要な見出しを載せ、キャラクター個々への移動は折りたたみ式一覧から行う想定。
- キャラクターごとの独立した個別ページを基本形にはせず、まずは1ページ内で一覧と詳細を完結させる。
- 一般的な基本データを網羅するのではなく、キャラクター固有の特徴、性能の活かし方、構築や立ち回りなど、通常のWikiより踏み込んだ攻略情報を中心にする。
- キャラクターごとの詳細解説は、準備できたものから順次追加できるようにする。

#### アンロック攻略

- 本編に最初から存在するすべてのアンロックを網羅する方針ではない。
- 基本的にDLCやアップデートで追加された新しいアンロックを対象にする。

### 3.2 DLC

- DLCごとに分類する。
- 各DLCの中に、そのDLCに関係する攻略情報をまとめる。
- ステージ攻略はステージごと、ボス攻略はボスごとに記事を作成する。
- DLCで追加されたキャラクターの性能解説を扱う。
- DLCで追加された新しいアンロックの攻略を扱う。

DLCごとにすべての種類の記事が必ず存在するとは限らない。実際に必要なコンテンツに合わせて掲載する。

## 4. 金策

攻略とは独立したメニューにする。大きく次の2種類の記事を扱う。

### 4.1 金策の仕組み・基本解説

ゴールドを稼ぐ仕組みや、金策に関係するキャラクター・武器・アルカナ・設定などを解説する。どのような仕組みでゴールドを稼げるのか、なぜ効率が上がるのかといった背景も扱い、個別の金策構築を理解するための基礎情報を提供する。

### 4.2 金策構築

キャラクターや金策方法に応じて、実際に使用する構築と稼ぎ方を紹介する。基本的にはnoteの記事構成を参考に、次の内容をひとつの記事内で扱う。

1. 目次
2. キャラクターの性能・評価
3. 使用ステージ・設定
4. **金策構築・実践方法**

「金策構築・実践方法」の中に、武器・パッシブ・アルカナなどの構成、取得順や立ち回り、実際の稼ぎ方、検証結果をまとめる。黄金の卵の段階によって構築が異なる場合も、原則として同じ記事内で紹介する。

検証結果は独立した大見出しにせず、実際の構築・稼ぎ方と関連付けて掲載する。稼げたゴールド量や所要時間などを示し、複数条件を比較する場合は表や画像などで分かりやすく整理する。

## 5. アップデート

バージョンごとに情報を整理するページを設けたい。

各バージョンで追加・変更された内容や、それに関連する攻略記事をまとめることを想定している。

速報性の高い情報はnoteで先に発信し、Webサイトでは後から参照しやすいように整理した情報を扱う。

具体的なページ構成や、DLCとの情報の分け方は今後検討する。

## 6. note

noteの最新記事や過去記事を紹介し、noteへ移動できるページを設ける。

基本的にはnoteで先に情報を発信するため、最新記事を見つけやすくしたい。

noteは単なる外部リンク先ではなく、サイトの強みの1つとして活用する。noteで先行公開した速報性のある情報と、Webサイトで整理した攻略情報を相互に案内し、読者が関連情報を行き来できるようにする。

ページの表示名は「note」「note記事」などを候補とし、まだ確定しない。

## 7. YouTube動画

YouTubeに投稿している動画をまとめて掲載する独立ページを設ける。

- 投稿動画の一覧を表示する。
- 動画をサイト内で再生できるようにする（YouTube埋め込み）。
- 攻略記事すべてに動画があるわけではないため、動画を各記事に必須とはしない。
- 関連する攻略記事がある場合は、必要に応じて相互にリンクする。

ページの表示名は「YouTube」「動画」などを候補とし、まだ確定しない。

## 8. 記事の管理単位（現時点の決定）

| コンテンツ | 記事を作る単位 |
|---|---|
| ステージ攻略 | ステージごと |
| ボス攻略 | ボスごと |
| キャラクター攻略 | 本編・DLCごとのページに一覧＋ページ内リンク付きのキャラクター詳細を掲載 |
| アンロック攻略 | DLC・アップデートで追加された新規アンロックを中心に扱う |
| DLC | DLCごとに情報を分類 |
| 金策の仕組み・基本解説 | 仕組み・テーマごと |
| 金策構築 | キャラクター・金策方法ごと（卵数段階などの構築差は同一記事内にまとめる） |
| アップデート | バージョンごと（詳細は未決定） |
| note | 最新記事・過去記事へのリンク |
| YouTube | 投稿動画の一覧・埋め込み |

## 9. 訪問・閲覧の考え方

読者は「このWikiを見て何かを探す」というより、「知りたい情報があるから、このサイトを見る」という目的を持って訪れることを想定する。

そのため、検索エンジンやnote、YouTubeなどから個別記事へ直接アクセスするケースを重視する。

個別記事はトップページを見ていなくても、記事単体で目的や内容が分かり、必要な情報に到達できるようにする。カテゴリー一覧や関連記事は、目的の情報を探したり、関連情報へ移動したりするための補助として設計する。

トップページは重要な入口の1つではあるが、必ず経由する前提にはしない。

## 10. 今後検討すること

- ホームに表示するコンテンツとその優先順位
- 攻略ページから本編・DLCを選ぶ導線
- DLC内の情報の見せ方
- 折りたたみ式キャラクター一覧の配置・開閉方法や、詳細解説への移動方法
- キャラクターごとの詳細解説に掲載する内容
- 金策構築ごとの実践手順・比較情報の見せ方
- アップデートページとDLCページの役割分担
- note記事一覧の表示方法や連携・更新方法
- YouTube動画一覧の表示方法や連携・更新方法
- グローバルメニューの最終的な表示名
- 個別記事へ直接訪問した読者のためのページ構成・案内
- スマートフォンでのナビゲーションとページ構成
- どのクリック・閲覧行動を計測するか
- 計測結果をどのようにサイト改善に使うか

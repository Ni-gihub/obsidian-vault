# サイト構成・コンテンツ分類

このノートでは、Vampire Survivors攻略サイトのページ構成、グローバルメニュー、記事を作る単位を整理する。

現時点で決まっている内容と、今後検討する内容を区別する。未決定の項目を無理に確定させない。

## 1. グローバルメニュー案

現時点の候補：

1. ホーム
2. 攻略
3. 金策
4. アップデート
5. note（表示名は検討中）
6. YouTube動画（表示名は検討中）

noteとYouTubeは、攻略記事の中に必ず含めるのではなく、それぞれ独立したコンテンツページを用意する。

## 2. ホーム

ホームは、**サイト内にあるすべてのコンテンツへの案内役・全体案内図**として設ける。

読者がサイトに何の情報があるのかを把握し、目的に合ったページへ移動できるようにする。主要なコンテンツの入口を整理して掲載し、各カテゴリ・一覧ページを経由して個別の記事にもたどり着ける構成にする。

案内する主なコンテンツは以下。

- 攻略：本編・DLC、ステージ攻略、ボス攻略、キャラクター情報、アンロック攻略
- 金策：金策の仕組み・基本解説、金策構築
- アップデート：バージョンごとの更新情報
- note：既存のリンク集と、Webサイト側のタグで分類したnote記事
- YouTube：新しい順に並べた投稿動画

ホーム上に個別記事をすべて並べるのではなく、コンテンツのまとまりごとに入口を設け、各一覧・カテゴリページから個別記事へ進めるようにする。

検索エンジン・note・YouTubeなどから個別記事へ直接訪問するケースも引き続き重視する。ホームは全体を見渡すための案内ページであり、すべての読者が必ず経由する前提にはしない。

具体的な表示順やレイアウトは、ページ内容の整理後に検討する。

## 3. 攻略

攻略トップでは、本編・DLCを最初に選ばせるのではなく、**攻略したいコンテンツの種類から選べるようにする**。

攻略トップに表示する主な入口は次の4種類とする。

- ステージ攻略
- ボス攻略
- キャラクター情報
- アンロック攻略

本編とDLCは独立した選択専用ページを挟まず、それぞれの種類の一覧ページ内で分類する。読者は「ステージ攻略」「ボス攻略」など目的の種類を選んだ後、その一覧の中で本編または目的のDLCの情報を探せるようにする。

### 3.1 ステージ攻略

- ステージごとに攻略記事を作成する。
- ステージ攻略の一覧ページ内で、本編のステージとDLCごとのステージを分けて掲載する。
- **並び順は本編を最初にし、その後にDLCを掲載する。DLCは新しいものから順番にする。**
- 一覧には、基本的に**画像とステージ名のみ**を表示する。短い説明文や詳細な攻略情報は載せず、攻略記事側で確認してもらう。
- 本編と各DLCの区切りは、基本的に見出しや区切り線で表現する。
- **カード形式は現時点で採用を決めていない。** 画像と名称をどのようなレイアウトで並べるかは、参考サイトを調査してから決める。
- 30分生存など、そのステージのクリアを目的とした攻略を扱う。

### 3.2 ボス攻略

- ボスごとに独立した攻略記事を作成する。
- ボス攻略の一覧ページ内で、本編のボスとDLCごとのボスを分けて掲載する。
- **並び順は、基本的にボスが出現するステージの順番にする。**
- 一覧には、基本的に画像とボス名を表示する。
- ボスの倒し方や、撃破に必要な準備・手順を扱う。

### 3.3 キャラクター情報

- 本編・DLCごとにキャラクター情報をまとめる。
- 本編と各DLCのキャラクター情報を、キャラクターごとの独立ページを選ぶ前の専用中継ページに分けるのではなく、キャラクター情報のまとまりの中で分類して見せる。
- キャラクターごとの独立した個別ページは作成しない。
- **本編と各DLCに分け、ゲーム内と同じ順番で掲載する。**
- 一覧・ページ内リンクは、画像とキャラクター名を基本とする。
- 各キャラクターの掲載内容は、基本的に「画像」「入手方法」「性能」の3つとする。
- 性能はゲーム内の説明をそのまま掲載するだけではなく、固有能力やステータスなどの効果・仕様を詳しく解説する。
- おすすめ武器・相性のよいアルカナ・運用評価などを全キャラクターに一律で設けず、必要な情報がある場合に性能の説明へ含める。
- キャラクター一覧は折りたたみ式とし、一覧内のキャラクター名から同じページ内の該当箇所へ移動できるようにする。
- 通常の目次にはページ全体の主要な見出しを載せ、キャラクター個々への移動は折りたたみ式一覧から行う。

### 3.4 アンロック攻略

- 本編に最初から存在するすべてのアンロックを網羅する方針ではない。
- 基本的にDLCやアップデートで追加された新しいアンロックを対象にする。
- アンロック攻略の一覧では、本編とDLCに分けて掲載する。
- **本編・各DLCの中では、ゲーム内と同じ順番で掲載する。**
- 一覧には、画像とアンロック名を基本とする。
- 追加されたDLCやバージョンなどのまとまりが分かるように整理する。

## 4. 金策

攻略とは独立したメニューにする。大きく次の2種類の記事を扱う。

### 4.1 金策の仕組み・基本解説

金策全体の知識をまとめ、個別の金策構築を理解するための基礎情報を提供する。基本構成は以下の8項目とする。

| 順番 | 見出し | 内容 |
|---|---|---|
| 1 | 目次 | 記事内の案内 |
| 2 | 金策の種類 | ゴールドフィーバー、金貨袋、悪食の瞳など |
| 3 | ゴールドフィーバーの仕組み | 発動条件、持続時間、延長、減衰など |
| 4 | 金策向けキャラクター | ビッグ・トラウザー、サミーなど |
| 5 | 金策向け武器 | 金策に使える武器と効果 |
| 6 | 金策向けアルカナ | それぞれの効果と採用する理由 |
| 7 | 金策に関係する設定 | ステージ設定、ゲーム速度、エフェクトなど |
| 8 | 効率の検証・比較 | 実際のプレイ結果を使った比較 |

キャラクター・武器・アルカナ・設定は、性能を並べるだけではなく、金策にどう役立つのか、なぜ採用するのかまで説明する。具体的な構築や実践手順は金策構築の記事で扱う。基本解説と構築記事はそれぞれ単体で目的を果たせる内容にする。必要な案内やリンクを配置する場合は、記事末尾に関連記事をまとめる方式ではなく、サイドバーなどページ横の領域に置く方法を検討する。

効率の検証・比較では、実際のプレイ結果を使い、検証した条件と結果が分かるようにする。確認できた内容と推測は区別する。

### 4.2 金策構築

キャラクターや金策方法に応じて、実際に使用する構築と稼ぎ方を紹介する。基本的にはnoteの記事構成を参考に、次の内容をひとつの記事内で扱う。

1. 目次
2. キャラクターの性能・評価
3. 使用ステージ・設定
4. **金策構築・実践方法**

「金策構築・実践方法」の中に、武器・パッシブ・アルカナなどの構成、取得順や立ち回り、実際の稼ぎ方、検証結果をまとめる。黄金の卵の段階によって構築が異なる場合も、原則として同じ記事内で紹介する。**金策構築の種類は、現状の2体のキャラクターによる構築を基本とし、新しい構築が実際に増えた場合に同じ一覧へ追加する。現時点で細かな分類や拡張用の複雑な仕組みは設けない。**

検証結果は独立した大見出しにせず、実際の構築・稼ぎ方と関連付けて掲載する。稼げたゴールド量や所要時間などを示し、複数条件を比較する場合は表や画像などで分かりやすく整理する。

## 5. アップデート

**バージョンごとにページを作成し、そのバージョン更新のうち、攻略サイトに関係する内容をまとめる。**

- バージョンを記事・ページの管理単位とする。
- そのバージョンで追加・変更された内容のうち、攻略情報に関係するものを掲載する。
- 無料アップデートとDLCの内容は分けず、同じバージョンのページ内で扱う。
- 更新内容を網羅的なパッチノートとして転載することを目的とせず、攻略情報として読者に関係する内容を選んで整理する。
- 既存の攻略方法に影響する変更があれば、そのバージョンページ内で変更点と影響を説明する。
- 記事末尾に関連記事・おすすめ記事をまとめる枠は設けない。必要な案内を置く場合は、サイドバーなどページ横の領域にまとめる形式を検討する。

速報性の高い情報はnoteで先に発信し、Webサイトでは後から参照しやすいようにバージョンごとに整理する。

## 6. note

noteページは、Webサイトからnoteへ移動するためのシンプルな入口として設ける。noteの記事内容をWebサイト側で詳しく紹介したり、独自の大規模な記事アーカイブを作ったりすることは目的にしない。

ページの構成は次のとおり。

1. **既存のnoteリンク集を最上部に掲載する。**  
   [note記事のリンク集](https://note.com/neo_magical/n/n6770c38d1b1c) を、noteに掲載している記事全体を探すための入口として案内する。
2. **その下に、Webサイト側でタグを付けたnote記事をタグごとに分けて掲載する。**  
   読者がWebサイト上で分類を選び、目的に近いnote記事へ移動できるようにする。

noteページはnoteへの入口として必要な案内に絞り、記事ごとの長い説明や複雑な検索・絞り込み機能などは、必要性が出るまで設けない。

タグの種類や各記事への付け方は、今後整理する。

## 7. YouTube動画

YouTubeページは、WebサイトからYouTubeへ移動するためのシンプルな入口として設ける。動画をWebサイト内で詳しく解説したり、独自の動画アーカイブとして作り込んだりすることは目的にしない。

- 投稿した動画を**新しい順**に並べて掲載する。
- 動画を見たい読者は、一覧からYouTubeへ移動して視聴する。
- YouTubeページ内で動画を埋め込んで再生することは基本としない。
- 攻略に直接関係する動画は、該当する攻略ページに埋め込む。YouTubeページと攻略ページで役割を分ける。

ページは最新動画を見つけてYouTubeへ移動できる程度のシンプルな構成にする。

## 8. 一覧ページの共通方針

サイト内の各コンテンツ一覧では、**原則として検索・ソート・フィルター機能を設けない**。

- カテゴリやコンテンツのまとまりをあらかじめ分け、分かりやすい固定順で掲載する。
- 読者はGoogleなどの検索エンジンで目的の情報を探してから訪問することが多い想定のため、一覧ページでもう一度検索や絞り込みをさせない。
- 利用頻度が高くないと考えられる機能を追加して、読者に余分な操作を求めない。
- 一覧の情報量が増えても、まずは分類と並び順を工夫して目的の記事を見つけやすくする。
- ステージ・ボス・キャラクター・アンロックなど、個別コンテンツを一覧表示する場合は、**基本的に画像と名称のみ**を表示する。詳しい説明文や性能情報は一覧に詰め込まず、移動先の記事・ページ内の解説で確認してもらう。
- 本編と各DLCの区切りは、基本的に見出しや区切り線で表現する。
- **カード形式を含む具体的なレイアウトは未決定**とする。カードを前提にせず、参考サイトの一覧表示を比較してから決める。特にスマートフォン表示は、複数のサイトを参考にしながら時間をかけて試行錯誤する。

この方針はステージ・ボス・キャラクター・アンロックなど、サイト内の各一覧ページに共通して適用する。

## 9. 記事の管理単位（現時点の決定）

| コンテンツ | 記事を作る単位 |
|---|---|
| ステージ攻略 | ステージごと |
| ボス攻略 | ボスごと。ボス一覧は本編・DLC別に分け、基本的に出現ステージ順で掲載 |
| キャラクター攻略 | 本編・DLCごとのページに一覧＋ページ内リンク付きのキャラクター詳細を掲載。各グループ内はゲーム内順 |
| アンロック攻略 | 本編・DLC別に分け、各グループ内はゲーム内順で掲載。DLC・アップデートで追加された新規アンロックを中心に扱う |
| DLC | DLCごとに情報を分類 |
| 金策の仕組み・基本解説 | 仕組み・テーマごと |
| 金策構築 | キャラクター・金策方法ごと（卵数段階などの構築差は同一記事内にまとめる） |
| アップデート | バージョンごと（無料アップデートとDLCを同じページで扱い、攻略サイトに関係する追加・変更内容を掲載） |
| note | 既存のnoteリンク集を先頭に掲載し、その下にWebサイト側で付与したタグごとにnote記事へのリンクを整理 |
| YouTube | 投稿動画を新しい順に並べた一覧から、YouTubeへ移動する入口 |

## 10. 訪問・閲覧の考え方

読者は「このWikiを見て何かを探す」というより、「知りたい情報があるから、このサイトを見る」という目的を持って訪れることを想定する。

そのため、検索エンジンやnote、YouTubeなどから個別記事へ直接アクセスするケースを重視する。

個別記事はトップページを見ていなくても、記事単体で目的や内容が分かり、その記事内で必要な情報に到達できるようにする。**記事末尾に関連記事やおすすめコンテンツを並べることはしない。** サイト内の案内や使いやすさを補助する情報は、基本的にページ横のサイドバーに配置する。記事末尾に関連記事をまとめる形式は採用しない。サイドバーの具体的な掲載項目や、スマートフォンでの表示方法はデザイン検討で決める。

トップページは重要な入口の1つではあるが、必ず経由する前提にはしない。

## 11. 今後検討すること

- ホームでの各コンテンツ入口の表示順・レイアウト
- 各攻略カテゴリ一覧での画像・名称の具体的な表示レイアウト
- ステージ・ボス・キャラクター・アンロック一覧の画像素材・比率・トリミング方法
- 折りたたみ式キャラクター一覧の配置・開閉方法や、同じページ内の該当箇所への移動方法
- 金策構築ごとの実践手順・比較情報の見せ方
- バージョンページ内での更新内容の並び順・詳細度
- noteページで使用するタグの種類と、各記事へのタグ付け
- YouTube一覧に表示する情報（タイトル・サムネイルなど）と更新方法
- グローバルメニューの最終的な表示名
- 個別記事へ直接訪問した読者のためのページ構成・案内
- スマートフォンでのナビゲーションとページ構成
- どのクリック・閲覧行動を計測するか
- 計測結果をどのようにサイト改善に使うか

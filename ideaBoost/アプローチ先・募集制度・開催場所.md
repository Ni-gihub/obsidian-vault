# アプローチ先・募集制度・開催場所

更新日：2026-11-12

Idea BoostのToB・ToC向けアプローチ先、企業・団体・自治体制度・開催場所・集客サイトを整理する。

企業の導入事例は、現在Idea Boostを募集していることや導入意向があることを意味しない。募集・受託実績・一般的な問い合わせ先を区別して記載する。

## アプローチ方法の全体像

| 対象 | 方法 | 自分たちの役割 |
|---|---|---|
| ToB | ① 企業向け研修を提供している会社 | 協業パートナー・外部講師・ツール提供者 |
| ToB | ② 授業・ワークショップ・イベントを実施する企業・団体 | プログラム協力者・共同企画者 |
| ToB | ③ 自社で研修・アイデア創出を行っている企業 | サービス提供者 |
| ToB | ④ 企業が参加するイベントに参加する | イベント参加者・協業候補との接点づくり |
| ToC | ① SNS・Webでの認知獲得 | 情報発信者・サービス提供者 |
| ToC | ② 自主イベントの開催 | イベント主催者・講師・ファシリテーター |

## ToB① 企業向け研修を提供している会社への営業

この分類では、企業の社員を対象に研修・人材育成プログラムを提供している会社を扱う。会社の主業が研修専業であるかは問わないが、単なる新規事業コンサルティングや事業開発の伴走支援だけの場合は、①の主要候補と区別する。

Idea Boostとの接点を判断するため、各社について「何を提供しているか」だけでなく、「どのような進め方で研修を行うか」「どの企業に提供した実績があるか」も整理する。

### 研修会社に提案するときの流れ

1. 研修内容・対象者・実施時間・参加人数・既存の進行方法を調べる。
2. 既存研修のどの工程でIdea Boostを使うと価値が出るかを1つに絞る。
3. 研修会社のプログラムや独自メソッドを置き換えず、アイデアの発散・共有・整理・選定を支援する形でデモを提案する。
4. 既存研修の一部で試験利用するか、Idea Boostを組み込んだ共同ワークショップを企画する。
5. 講師・運営者・参加者からフィードバックを受け、操作性・進行時間・成果物の質を確認する。
6. 効果が確認できた場合は、別の研修コース・別顧客・継続プログラムへの展開を相談する。

### 実績情報を読むときの注意点

- 企業名・参加人数・期間・実施内容まで公開された事例と、研修メニューだけが公開された企業を区別する。
- 会社が新規事業支援・コンサルティングを行った実績を、すべて研修の導入実績として扱わない。
- 企業名が非公開の場合は、無理に推測せず「A社」「大手情報通信会社」など、公開元の表現に合わせる。
- 同じ企業の別テーマの研修実績を、今回検討している新規事業開発研修の導入実績と混同しない。
- 実施事例があっても、現在その企業が新規パートナーや外部ツールを募集していることを意味しない。問い合わせ時に現行の研修提供状況・導入余地を確認する。

### 直接営業での提案方法

1. 企業のニュース・導入事例から、研修・社内アイデアソン・新規事業制度の有無を調べる。
2. 人事・人材育成、DX推進、新規事業のうち、テーマに合う部署を探す。
3. 「Idea Boostを導入してください」だけでなく、相手の取り組みに合わせて利用場面を提示する。
4. 全社導入ではなく、1部署・1チーム・1回の試験利用を提案する。
5. 実施後に参加者数、アイデア決定まで進めたか、参加者・運営者の感想を記録する。

提案例：
- 人材育成担当：若手社員がチームで職場の課題を見つけ、改善案を選ぶ研修
- DX担当：現場の困りごとを出し合い、生成AI・デジタル活用案を選定するワークショップ
- 新規事業担当：社内ビジネスコンテストの前段で、課題整理から事業アイデアの絞り込みを行うワーク

### 神戸市のDX人材育成補助制度

[2026年度 神戸市中小企業DX推進支援補助制度（DX人材育成事業）](https://www.city.kobe.lg.jp/a93457/2026dxjinzai.html)

- 神戸市内の中小企業が、DXに関する研修・講座を受講する費用を補助する制度。
- 補助率は対象経費の2分の1以内、上限は1件30万円。
- 2026年度の公募期間は2026年6月1日〜2027年1月29日17時。
- 受講時間は1人あたり合計6時間以上が要件。
- 企業側は「神戸市中小企業DXお助け隊事業」の面談を受ける必要がある。
- オーダーメイド講座の場合、外部講師の謝金・交通費・宿泊費も対象経費に含まれ得る。

Idea Boostを使ったDX・業務改善ワークショップを有料研修として提供する場合、企業側の費用負担を抑える提案材料になる可能性がある。ただし、Idea Boostの研修が補助対象になると確定したわけではない。内容・時間・講師謝金の扱いを神戸市へ事前確認する。

## ToB④ 企業が参加するイベントに参加する

企業の担当者や新規事業・DX・人材育成に関わる人が参加するイベントに参加し、Idea Boostを知ってもらう接点を作る。イベントへの参加自体を目的にせず、Idea Boostの利用につながる企業・担当者との会話や、その後の商談・デモにつなげる。

### 参加するイベントの候補

- 新規事業開発・オープンイノベーション・イノベーション人材育成に関するカンファレンス
- DX・生成AI・業務改善・デジタル人材育成に関する展示会やセミナー
- 人事・人材開発・企業研修・組織開発に関するイベント
- 企業とスタートアップ、大学、自治体が交流するビジネスマッチング・共創イベント
- 研修会社・コンサルティング会社・企業の新規事業担当者が登壇・出展するイベント

### 参加前に調べること

1. イベントの参加対象者、登壇企業、出展企業、協賛企業を確認する。
2. 研修会社、新規事業開発会社、DX推進企業、事業会社の人材開発・新規事業担当など、Idea Boostと接点がある企業を絞る。
3. 参加目的を「導入候補との面談」「協業先の発見」「利用者の声の収集」などに設定する。
4. Idea Boostの短い説明資料、デモ環境、QRコード、連絡先を準備する。

### 当日の動き・イベント後のフォロー

- 参加企業の担当者に、現在どのような研修・ワークショップ・アイデア創出活動を行っているかを聞く。
- Idea Boostを売り込むだけでなく、相手のプログラムで課題になっている工程や既存ツールを確認する。
- 興味を持った相手には、後日デモ・意見交換・試験利用を提案する。
- イベント後は、会話した企業・担当者・関心テーマ・次のアクションを記録し、個別に連絡する。

イベント参加者全員に営業できるわけではない。また、参加企業・来場者の一覧や個人連絡先が公開・提供されるとは限らないため、公式に公開されている登壇者・出展者情報や、当日の交流を通じて接点を作る。

### 自主イベントの始め方

1. 対象者とテーマを1つ決める（例：社会人向け「身近な業務課題から改善アイデアを考える」）。
2. 参加人数を小さく設定し、Idea Boostを使う範囲を決める。
3. 会場・開催形式・所要時間・参加費を決める。
4. Peatixやconnpassで募集し、知人・コミュニティにも告知する。
5. 当日はワークショップを進行し、終了後にアンケートやヒアリングで評価を集める。
6. 実績を次の企業・研修会社・自治体への提案資料にする。

## 優先順位と進め方

今回決定した6つの方法を一度に大規模に始める必要はない。まずは既に研修・授業・イベントの利用機会を持つ企業・団体に接点を作り、自主イベントで実施実績を作る。

| 優先 | 取り組み | 目的 |
|---|---|---|
| 1 | デザインスプリント研修会社・授業/イベント運営会社へ提案 | 既存プログラムでの試験利用・共同企画 |
| 2 | 自社で研修・アイデア創出を行う企業へ提案 | 社内研修・アイデアソンでの試験導入 |
| 3 | 企業が参加するイベントに参加 | 企業担当者・協業候補との接点づくり |
| 4 | 小規模な自主イベントを開催 | 利用者の感想・実施実績・改善点を集める |
| 5 | SNS・Webで発信 | イベント参加者・サービス利用者を増やす |

※優先順位は現時点の仮説。実際の連絡先・募集状況・協力可能性に応じて調整する。

## 企業・団体へ連絡する前に用意したいもの

- Idea Boostの説明・操作デモ
- ワークショップの概要（目的、対象者、進行、所要時間、参加人数、成果）
- 運営体制（講師、ファシリテーター、当日のサポート）
- 費用・交通費・会場費の考え方
- 個人情報・機密情報・成果物の扱い
- これまでの利用実績と、未実施・未検証の内容の区別

最初から大きな成果を約束するのではなく、Idea Boostを使った体験型のアイデア創出ワークショップや既存プログラムの一部での試験利用から始める。
